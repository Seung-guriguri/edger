# Edger 📊

[edgartools](https://github.com/dgunning/edgartools) 기반의 **모바일 우선** SEC EDGAR 기업 대시보드 (Streamlit).

### 🔎 종목 화면
- 맨 위에 회사명·주가·등락·시총·PER이 한 덩어리로 보이고, ☆로 관심종목에 추가합니다.
- **한눈에 보기**: 밸류에이션(과거 PER 대비)·성장·수익성·재무 안정성을 한 줄씩 판정합니다.
  기준값을 함께 적어 두어 판정을 직접 확인할 수 있습니다 (참고용, 투자 판단 아님).
- 업종에 따라 화면이 바뀝니다: **은행**(순이자이익·효율성 비율·대손비용·자기자본비율),
  **보험**(보험료 수익), **리츠**(FFO 추정·P/FFO·차입금/총자산).
- **외국 기업(20-F)**: 재무 통화를 주가 통화로 환산해 PER 등을 계산하고, 실적이 오래됐으면 경고합니다.
  SEC에 분기 데이터가 없으면 **Yahoo Finance의 최근 5~7개 분기**로 분기·TTM을 채우고 출처를 표시합니다.
- 상단의 **연간 | TTM | 분기** 로 실적 카드와 재무 탭의 기준을 바꿉니다.
  TTM은 각 분기 시점의 최근 4분기 합계로, 계절성 없이 매 분기 추세를 볼 수 있습니다.
- **핵심 지표**: 주가·시가총액(PER), 최근 회계연도 매출·순이익·영업이익률·ROE와 전년 대비 변화
- **📈 재무**: 연간/분기 매출·영업이익·EBITDA·순이익·EPS·FCF·배당(DPS)·주식수 추이, 마진(EBITDA 마진 포함),
  ROE·ROIC·ROA, 1년·3년·5년 성장률(CAGR), 재무 안정성(순차입금·부채비율·유동비율·이자보상배율·순차입금/EBITDA),
  **전체 재무제표**(최근 10-K/10-Q 원문 XBRL 기준 손익·재무상태·현금흐름)
- **🏢 사업**: 연간 보고서(10-K·20-F) 첫 부분의 사업 개요(영문), **매출 구성**(사업부문·제품·서비스·지역별 금액과
  비중, 전년 대비 증감, 부문별 영업이익률), 연도별 구성 변화. 연간 보고서 XBRL의 차원 데이터에서 직접 읽습니다.
- **💹 가치**: **TradingView 차트**(캔들·보조지표·그리기, 종목 변경 가능) 또는 간단 차트,  주가 차트(1~10년), 52주 최고·최저,
  밸류에이션(PER·PBR·PSR·P/FCF·EV/EBITDA·EV/EBIT·EV/매출·PEG), 주당 지표(EPS·BPS·DPS),
  연도별 PER과 현재 PER 비교
- **💰 배당**: 역대 배당 내역(연도별·회차별 그래프), 연도별 배당수익률, 최근 12개월 배당, 연속 배당·연속 증액 햇수,
  5·10년 배당 성장률, 주주환원(배당성향·자사주 매입액·총 주주수익률). 배당 내역은 Yahoo Finance,
  실패하면 SEC 공시의 주당배당금으로 대신 보여줍니다.
- **📄 공시**: 10-K(사업 개요·리스크 요인·MD&A), 10-Q, 8-K(항목별 내용·보도자료)를 **앱 안에서 읽기**,
  종류별 공시 목록
- **👤 내부자**: 최근 Form 4 거래, 장내 매수·매도 합계와 월별 차트

### ⭐ 관심·비교 화면
- 관심종목 표(주가, 일간 변동, 시총, PER, 매출 증가율, 영업이익률, ROE) — 행을 누르면 종목 화면으로
- 최대 5개 종목을 골라 매출·성장률·마진·ROE·ROIC 추이 비교
- 관심종목은 **폰 브라우저에 저장**되어 다시 열어도 유지됩니다 (계정 불필요)

네트워크 없이 둘러보려면 티커에 `DEMO` 를 입력하세요. 관심·비교 화면에서는 `DEMO DEMOB DEMOC` 를 추가하면
예시 회사 3곳을 비교해 볼 수 있습니다.

## 로컬 실행

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # 이름과 이메일 입력
streamlit run app.py
```

SEC는 모든 요청에 `이름 이메일` 형태의 User-Agent를 요구합니다. `secrets.toml` 이나 환경변수
`EDGAR_IDENTITY` 로 설정하거나, 설정하지 않으면 앱 첫 화면에서 입력받습니다.

### 같은 와이파이의 폰에서 보기

`streamlit run app.py` 출력의 **Network URL** (예: `http://192.168.0.10:8501`)을 폰 브라우저에서 엽니다.

## 폰에서 어디서나 쓰기 (무료 배포)

1. 이 저장소를 GitHub에 푸시
2. [share.streamlit.io](https://share.streamlit.io) 에서 저장소 연결, 메인 파일 `app.py` 선택
3. 앱 설정 → **Secrets** 에 `EDGAR_IDENTITY = "Your Name you@example.com"` 입력
4. 폰 브라우저로 URL을 열고 **홈 화면에 추가** 하면 앱처럼 실행됩니다

`?t=AAPL` 처럼 URL에 티커를 넣으면 바로 그 종목이 열리므로, 자주 보는 종목은 북마크해 두면 편합니다.
무료 플랜은 한동안 접속이 없으면 잠들어서 첫 접속에 30초 정도 걸릴 수 있습니다.

## 참고

- SEC 데이터는 6시간, 주가는 15분 캐시합니다 (SEC 요청 제한: 초당 10회).
- 주가는 SEC에 없어서 Yahoo Finance(yfinance)에서 가져오고, 실패하면 Stooq(무료 일별 시세)로 대신합니다.
  둘 다 실패해도 재무·공시 탭은 그대로 동작하고, 주가·가치 탭의 "주가 다시 불러오기"로 재시도할 수 있습니다.
  실패한 결과는 캐시하지 않습니다(90초 뒤 자동 재시도).
- 재무 안정성은 상단 기준과 상관없이 **최근 분기말 재무상태 + 최근 4분기(TTM) 실적**으로 계산합니다.
  부채비율(총부채÷자본, 한국식)과 D/E(차입금÷자본, 미국 앱의 Debt/Equity)는 다른 지표라 따로 보여줍니다.
- 실데이터 검증 결과는 [docs/VERIFICATION.md](docs/VERIFICATION.md) 에 있습니다.
- 시가총액: Yahoo 시가총액 → 주가 × SEC 공시 발행주식수 → 주가 × 희석주식수(추정) 순서로 계산합니다.
  시가총액 카드의 ? 에 어떤 방식이 쓰였는지 나옵니다.
- 밸류에이션은 최근 4분기 합계(TTM) 기준이며, 분기 데이터가 부족하면 최근 회계연도로 대신합니다.
- EBITDA = 영업이익 + 감가상각비. 감가상각비 태그가 없는 회사는 EBITDA 관련 지표가 – 로 나옵니다.
- 전체 재무제표는 최근 10-K/10-Q의 XBRL을 읽고, 실패하면 XBRL 요약 데이터에서 재구성하며,
  그것도 안 되면 주요 항목만 보여줍니다. 표 아래 '출처'에 어느 방식인지 표시됩니다.
- ROIC의 차입금은 XBRL 태그 기준 추정치입니다 (리스 부채 등은 제외될 수 있음).
- 내부자 탭은 Form 4 한 건당 SEC 요청 1회가 필요해 처음 열 때 몇 초 걸립니다.
- 재무 수치는 회사가 제출한 XBRL 태그에서 계산하므로 회사별로 일부 항목이 비어 있을 수 있습니다.
  투자 판단 전 원문 공시를 확인하세요.
